# 決算をまたぐかどうか

過去の決算日は Nasdaq の決算カレンダー（1日ごと、2015年〜）から取った（`tools/fetch_earnings_history.py`）。決算日のある銘柄 600、決算日が分かる銘柄の合図 3249件 / 3249件。決算が寄り付き前・時刻不明ならその日、引け後なら翌営業日を「決算で株価が動く日」とした。

## 決算をまたいだ売買と、またがなかった売買（今のルール、全部の合図）

| | 件数 | 勝率 | 1回平均 | 15%以上の損の割合 |
|---|---|---|---|---|
| 決算をまたいだ | 875 | 61% | 2.58% | 12% |
| またがなかった | 2374 | 65% | 1.28% | 12% |

## 決算の前に買わない・決算の前に売る

今のルール: 年率 26.5%、最大下落率 33.1%、設計期間 20.2%、確認期間 37.7%（乱数50通り）

| 形 | 年率 | 最大下落率 | 設計期間 | 確認期間 | 両方の期間で上回ったか |
|---|---|---|---|---|---|
| 決算の5営業日前までに入る合図は買わない | 28.5% | 32.8% | 21.7% | 38.0% | はい |
| 決算の10営業日前までに入る合図は買わない | 28.2% | 33.0% | 18.7% | 44.1% |  |
| 決算の20営業日前までに入る合図は買わない | 18.5% | 37.4% | 15.0% | 26.4% |  |
| 保有中は決算の前日の寄り付きで全部売る（全部のルール） | 16.5% | 34.3% | 10.6% | 28.0% |  |
| 保有中は決算の前日の寄り付きで全部売る（順張りだけ） | 18.2% | 35.2% | 14.4% | 25.9% |  |
| 保有中は決算の前日の寄り付きで全部売る（押し目・急落の底だけ） | 24.5% | 32.1% | 16.5% | 40.2% |  |


## 乱数を変えた確認（3組）

| 形 | 組1（5000番台・50通り） 年率／設計／確認 | 組2（7300番台・50通り） | 組3（1000番台・20通り） | 3組とも両方の期間で上回ったか |
|---|---|---|---|---|
| 今のルール | 26.5%／20.2%／37.7% | 26.5%／21.0%／38.3% | 27.1%／21.1%／36.9% | |
| 決算の5営業日前までに入る合図は買わない | 28.5%／21.7%／38.0% | 29.4%／21.9%／42.1% | 28.3%／20.2%／40.3% | いいえ（組3の設計期間が下回る） |
| 決算の10営業日前までに入る合図は買わない | 28.2%／18.7%／44.1% | 28.3%／20.0%／45.4% | 27.8%／17.5%／42.1% | いいえ（設計期間が3組とも下回る） |

## 結論（Claudeのまとめ）

- **決算をまたいだ売買の方が成績が良い**（1回平均 +2.58% 対 +1.28%、大きな損の割合は同じ12%）。決算で上に跳ねる銘柄を持てているため。
- **決算の前に売る形は、どれも年率が大きく下がる**（26.5%→16.5〜25.2%）。決算の上げを取り逃がす。
- **決算の5営業日前までに入る合図を買わない形**は、3組中2組で両方の期間を上回り、年率は+1〜3ポイント。ただ組3では設計期間が下回り、10営業日にすると設計期間は3組とも下がる（日数で結果が入れ替わる）。採用の基準（3組とも両方の期間で上回る）は満たさないため、**惜しい候補として記録だけ残す**。

- 決算の前日の寄り付きで売る形は、決算の2営業日前の引けで判定する（引け後の決算なら決算日の寄り付き、寄り付き前の決算なら前日の寄り付きで売ることになる）。
- この結果はルールの条件どおりに機械的に計算したもので、Claudeによる個別銘柄の売買判断ではない。
