# M1（選びすぎの確率）を保留中の形に当てる

2026-11-15、ユーザーの指示「バックテストして」。採用の目安の5つ目の案「選びすぎの確率が両方の監視銘柄で30%未満」（Fableの提案 `Fableの提案_確かめ方_2026-11-15.md` 1節）を、保留中の形に当てたら何が起きるかを確かめた。ルールは変えていない。

- 選びすぎの確率: 2015年〜を重ならない区切り（1年の区切り）か16個のブロック（毎日の資金）に分け、半分の期間で一番良かった形が、残りの半分で比べる元を下回る割合（分け方の全部で数える）。
- 「組」: その形を見つけた調べで、一緒に試した形の全部。組が大きいほど、偶然に良く見える形が出やすいので、確率は上がる。
- K=1: その形1つだけを、比べる元と比べた場合（たくさん試した中から選んだことを割り引かない）。
- t値: 比べる元との差の、ばらつきに対する大きさ。「偶然の一番の t値」は、組の形が全部偶然のときに出る一番大きい t値の上位5%（これを超えれば、試した数を割り引いても偶然とは言いにくい）。

## 1. 結論

| 形 | 1つだけで比べる（K=1） 87銘柄 / 全業種 | 一緒に試した形の組で比べる 87銘柄 / 全業種 | 5つ目の目安（30%未満） |
|---|---|---|---|
| QQQ＋ステージ2の後40日は2倍ETF（QQQの上に足すステージ2の分） | **14.6% / 13.5%**（毎日の資金）、23〜26% / 23%（1年の区切り） | 保留の3形の組 52.0% / 38.4%、全部の形のやり直しの14形 43.2% / 23.3%、底の合図53形 54.3% / 44.5% | 1つだけなら通る。**組で見ると通らない** |
| 2倍ETFをいつでも使う | **67.2%** / 7.0% | 同上 | 通らない（87銘柄で今より悪い） |
| 信用①6銘柄・信用取引1.5倍 | **38.0% / 39.2%** | 同上 | 通らない（最大下落率も 49%→65%・35〜39%→56%） |
| 策2 手数料のアドバンス | 0.0% / 0.0%（t値 15） | 0.0% / 0.0% | 通る（手数料が下がる分は偶然ではない） |
| 策1 税の払い方 | — | 31.1% / 10.5% | この物差しに向かない（税を払う日だけに差が出る） |

- **5つ目の目安の効き方は、「組」をどう決めるかで大きく変わる。** 1つだけで比べる形では目安は甘く（t値が0.5くらいでも通る）、保留中の QQQ＋ステージ2 は通る。一緒に試した形の組で比べる形（Fableの提案の形）では、QQQ＋ステージ2 は14形・53形・417形のどの調べでも、どちらかの監視銘柄で30%を超え、t値（87銘柄 2.2〜2.3・全業種 1.4〜1.7。QQQと比べると約1.0）も、試した数の分の「偶然の一番」に届かない。
- **QQQ＋ステージ2 の伸びの大部分は、もう採用しているQQQの分。** ステージ2の分だけだと、毎日の資金で年 +0.7pt（87銘柄）・+1.3pt（全業種）、ホワイトの検定 p=0.16・0.17（偶然でも6回に1回は出る大きさ）。税込みの通しでは 87銘柄 39.8%・38.7% → 41.2%・40.0%、全業種 29.7%・30.7% → 31.5%・32.3%。最大下落率は 87銘柄 49.0% のまま、全業種 34.9%・39.1% → 41.4%・41.3%。
- 「5回見つかった」のは、同じ2015年〜のデータを何度も調べ直した結果で、5回の別々の確かめではない。
- いつでも2倍ETF・信用取引は、5つ目の目安がなくても今の4つの目安（両方の監視銘柄・最大下落率）で採らない形なので、判断は変わらない。策2は、5つ目の目安を足しても通る。
- ルールは変えていない。保留の扱いも変えていない。
