# 銘柄の直近1年の最大下落率で、見送る・優先する・額を変える

合図の日までの直近1年（252取引日）で、その銘柄が高値から一番下がった割合（最大下落率）を使う。区切りの値は設計期間（2015〜2021年）の合図だけで決めた（中央値 18%、上位30%の境 23%、上位20%の境 28%）。土台は今のルール。判定は乱数3組（20通り・50通り×2）。


## 銘柄の下落率で見送る・優先する・額を変える

今のルール（乱数20通り）: 年率 19.1%、最大下落率 39.3%、設計期間 11.8%、確認期間 31.1%

| 形 | 年率 | 最大下落率 | 設計期間 | 確認期間 | ふるい |
|---|---|---|---|---|---|
| 1. 下落率が上位20%（28%以上）の合図を見送る | 10.9% | 35.8% | 8.8% | 16.5% |  |
| 1. 下落率が上位30%（23%以上）の合図を見送る | 11.1% | 45.1% | 8.8% | 16.3% |  |
| 1'. 押し目・急落の底だけ、上位20%を見送る | 14.6% | 38.4% | 8.0% | 28.5% |  |
| 1'. 順張りだけ、上位20%を見送る | 14.4% | 39.8% | 11.8% | 22.5% |  |
| 2. 枠が足りない日は、下落率の小さい銘柄を先に買う | 15.4% | 38.3% | 14.0% | 17.9% |  |
| 2'. （比較）枠が足りない日は、下落率の大きい銘柄を先に買う | 28.8% | 39.3% | 11.2% | 56.8% |  |
| 3. 下落率が上位20%の銘柄は額を半分（12.5%） | 13.2% | 36.1% | 8.4% | 20.1% |  |
