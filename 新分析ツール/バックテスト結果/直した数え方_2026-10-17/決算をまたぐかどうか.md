# 決算をまたぐかどうか

過去の決算日は Nasdaq の決算カレンダー（1日ごと、2015年〜）から取った（`tools/fetch_earnings_history.py`）。決算日のある銘柄 597、決算日が分かる銘柄の合図 8378件 / 8378件。決算が寄り付き前・時刻不明ならその日、引け後なら翌営業日を「決算で株価が動く日」とした。

## 決算をまたいだ売買と、またがなかった売買（今のルール、全部の合図）

| | 件数 | 勝率 | 1回平均 | 15%以上の損の割合 |
|---|---|---|---|---|
| 決算をまたいだ | 2496 | 59% | 3.59% | 10% |
| またがなかった | 5882 | 62% | 0.90% | 13% |

## 決算の前に買わない・決算の前に売る

今のルール: 年率 21.0%、最大下落率 39.2%、設計期間 13.3%、確認期間 30.3%（乱数50通り）

| 形 | 年率 | 最大下落率 | 設計期間 | 確認期間 | 両方の期間で上回ったか |
|---|---|---|---|---|---|
| 決算の5営業日前までに入る合図は買わない | 19.5% | 37.1% | 10.5% | 31.4% |  |
| 決算の10営業日前までに入る合図は買わない | 21.5% | 37.7% | 13.0% | 34.5% |  |
| 決算の20営業日前までに入る合図は買わない | 15.5% | 41.0% | 10.3% | 21.4% |  |
| 保有中は決算の前日の寄り付きで全部売る（全部のルール） | 17.7% | 39.5% | 11.9% | 25.4% |  |
| 保有中は決算の前日の寄り付きで全部売る（順張りだけ） | 18.4% | 40.3% | 12.4% | 26.5% |  |
| 保有中は決算の前日の寄り付きで全部売る（押し目・急落の底だけ） | 19.1% | 37.7% | 11.9% | 28.2% |  |

- 決算の前日の寄り付きで売る形は、決算の2営業日前の引けで判定する（引け後の決算なら決算日の寄り付き、寄り付き前の決算なら前日の寄り付きで売ることになる）。
- この結果はルールの条件どおりに機械的に計算したもので、Claudeによる個別銘柄の売買判断ではない。
