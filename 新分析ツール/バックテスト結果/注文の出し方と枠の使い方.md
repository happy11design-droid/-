# 注文の出し方と枠の使い方を工夫するバックテスト

  1. 候補が枠より多い日の選び方: ランダム（基本）／RSの高い順（今のツール）／値動き（ATR÷株価）の大きい順
  2. 押し目（ボリンジャーIII）・急落の底を、寄り付きの1%・2%・3%下の指値で買う（その日の安値が届かなければ買わない）
  3. 押し目の売りを、前日の引け時点の上のバンドの値段に指値を置いて、届いた日に売る（今は引けで上のバンド以上→翌日の寄り付き）

## 結論（Claudeのまとめ）

- **3. 押し目を上のバンドの値段の指値で売る形だけが、両方の期間で今のルールを上回った**（乱数2通りとも。設計 12.3%→14.3%・12.8%→13.6%、確認 25.2%→28.5%・24.7%→29.8%）。
  売値は今の形（引けで上のバンド以上→翌日の寄り付き）より少し低くなる（押し目の1回平均 2.03%→1.57%）が、上のバンドに届いた日に早く売れるため枠が早く空き、次の合図を買える回数が増える。最大下落率はやや大きくなる（33%→36%）。
  ただし、指値をバンドの1%上にすると確認期間で下回り（21.0%）、2〜3%下にすると設計期間で下回る（8.0〜11.4%）。良い範囲が「バンドちょうど〜1%下」と狭く、確かさは中くらい。
- 1. 値動きの大きい順に選ぶと、確認期間（2022年〜）は47.0%と大きく良いが、設計期間は12.3%→9.8%に下がる。AI・半導体の値動きの大きい時期に偏った結果。
- 2. 寄り付きより下の指値で買う形は、約定する回数が半分以下になり（届かない日は買えない）、1回平均は良くなるが年率は大きく下がった。押し目は寄り付き後にさらに下げずに戻る日の方が良い売買になるため。
- 4. 半分だけ利益確定して残りを伸ばす形は、残り半分が20日線・50日線割れまで持つ間に枠がふさがり、年率が下がった。
- 5. 含み損の銘柄と入れ替える形は、含み損の押し目はその後戻ることが多く、売ると損になって年率が下がった。
- → 3（押し目を上のバンドの指値で売る）は採用の候補。採用するかはユーザーの判断。

## 注意

- 指値の約定は日足の値幅で判定した近似（実際には同じ値段で約定しないこともある）。入れ替えの売値は前日の引けで近似。
- 押し目の売り方（3・4）は、元のルールの売り（引けで上のバンド以上→翌日の寄り付き）を、日足で作り直して比べている。
- 「RSの高い順」と「値動きの大きい順」は選び方の乱数の影響が小さいため10通り、ほかは50通りの中央値。
- この結果はルールの条件どおりに機械的に計算したもので、Claudeによる個別銘柄の売買判断ではない。
