# 銘柄の直近1年の最大下落率で、見送る・優先する・額を変える

合図の日までの直近1年（252取引日）で、その銘柄が高値から一番下がった割合（最大下落率）を使う。区切りの値は設計期間（2015〜2021年）の合図だけで決めた（中央値 18%、上位30%の境 24%、上位20%の境 29%）。土台は今のルール。判定は乱数3組（20通り・50通り×2）。


## 銘柄の下落率で見送る・優先する・額を変える

今のルール（乱数20通り）: 年率 27.0%、最大下落率 31.3%、設計期間 20.5%、確認期間 38.1%

| 形 | 年率 | 最大下落率 | 設計期間 | 確認期間 | ふるい |
|---|---|---|---|---|---|
| 1. 下落率が上位20%（29%以上）の合図を見送る | 16.4% | 32.2% | 17.0% | 15.8% |  |
| 1. 下落率が上位30%（24%以上）の合図を見送る | 12.8% | 31.5% | 16.1% | 12.9% |  |
| 1'. 押し目・急落の底だけ、上位20%を見送る | 23.3% | 29.9% | 18.4% | 28.3% |  |
| 1'. 順張りだけ、上位20%を見送る | 21.9% | 34.4% | 21.9% | 23.3% |  |
| 2. 枠が足りない日は、下落率の小さい銘柄を先に買う | 23.8% | 25.1% | 24.0% | 25.5% |  |
