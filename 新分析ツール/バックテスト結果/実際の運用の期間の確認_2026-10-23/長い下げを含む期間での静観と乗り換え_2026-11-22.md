# 長い下げを含む期間での静観と乗り換え（検証案A〜Dのまとめと最善策の提案）

2026-11-22、ユーザーの質問と指示「結局あなたが判定する銘柄は利益が出ずに損をしていると言う事ですか？…87銘柄全てに雲行きが怪しい。静観するか、上がっている銘柄に切り替えるかしないと損が膨らむだけ。…今までにないので今まで行った検証とは例外なため、イレギュラーな対応が必要だと感じています」→「全て検証して最善策を提案して」。

これまでの「下げの時期に止める・乗り換えると年率が下がる」という結論（20以上の形）は、個別株のデータがある2015年〜（すぐ戻る下げしかない期間）から出たもので、2000〜2002年・2007〜2009年のような長い下げでは確かめていなかった。そこで次の4つを行った。

| 検証 | 中身 | 詳しい結果 |
|---|---|---|
| A | 指数と業種ETF（1999年11月〜2026年11月20日）で、テーマ（SOX）から外れる合図5通り×戻し方2通り×行き先4通り（短期国債・上がっている業種・守りの業種・S&P500） | `長い下げ_A_指数と業種ETF_2026-11-22.md` |
| B | 今のルールの個別株の売買を1999〜2012年（S&P500の過去の構成銘柄のうち株価が残る銘柄）と2015年〜で、止める形・静観・乗り換えと比べる | `長い下げ_B_個別株_1999〜2012年と2015年〜_2026-11-22.md` |
| C | 「損切りが3回続いたら止める」を、Bの両方の期間と、毎朝のツールと同じ形（87銘柄・全業種、2倍ETF込み、1年の区切り×乱数3通り、株価11/20まで）で確かめ直す | 同上と `長い下げ_C_損切りが続いたら止める_毎朝のツールと同じ形_2026-11-22.md` |

## 1. 結論

1. **今の相場**（11/20の引け）: SOXは60日の最高値から−36.4%、87銘柄のうち50日線より上は6銘柄・200日線より上は14銘柄。S&P500の11業種で1か月プラスは生活必需品だけ（+0.5%）、金も−12.5%。①SOXとS&P500が両方200日線の下・③特殊な下げの印・④SOXが60日の最高値から−25%以下が出ている。
2. **ルールどおりの売買も損をしている**: 記録の合図を4銘柄の枠・2倍ETF込みで売買すると 12,000→7,624ドル（−36.5%、最大下落率37.7%）。週次レビューの見直しの目安（37%）を超えた。
3. **長い下げの期間でも、今のルールの売買は崩れなかった（B）**: 1999〜2012年、全業種の監視銘柄で年率+14.2%（最大下落率49%）、ITバブルの崩壊（2000-03〜2002-10）の間も+9%（SOXは−84%）。テーマの業種だけでは年率+8.9%、崩壊の間は−11%、金融危機は−17%（SOXは−62%）。損切り15%と売りのルールが大きな損を区切った。ただし破綻した銘柄の株価がないため実際より良く出ていて、テーマだけに集中した形ほど長い下げで弱い。
4. **静観（相場の合図で止める・全部売る）は、長い下げの期間を入れても1年の平均を下げた（A・B）**: 1999〜2012年でも、テーマの業種だけで −1.4〜−4.0pt（③特殊な下げの印で止める形だけ +1.0pt、ただし良かった区切りは29%）、全業種で −1.1〜−4.7pt。2015年〜は −1.2〜−10.9pt。長い下げの途中の急な戻り（2001年・2002年・2009年）を取り逃した。指数（A）でも、2000〜2002年はどの合図でも −65〜−87% の損になり、SOXの −84% をほとんど避けられなかった（崩壊の途中に何度も200日線・50日線を上回って戻り、また下げた）。
5. **上がっている業種・銘柄への乗り換えは、はっきりした良さがない（A・B・D）**: 指数では、テーマから外れている間の行き先は短期国債が一番よく（1999〜2012年 年率 −2.0%、上がっている業種 −3.9%）、上がっている業種は一番悪かった。個別株で「①の日は全業種から買う」は1年の平均が +0.8pt（1999〜2012年）・+2.3pt（2015年〜）だが、金融危機のように全部が下げる時期は損が大きくなり（最大下落率 34%→50%）、今回は①が出たのが11/18〜で効いていない。今回の期間（10/1〜11/20）では、上がっている銘柄（S&P500のRS上位4銘柄）も −28.3%、上がっている業種のETFも −10.1% で、損をしなかったのは短期国債（+0.6%）だけ。
6. **「損で終わった売買が3回続いたら新しい買いを止める」は、どの検証でも最大下落率を下げた（C）**:
   - 1999〜2012年（テーマの業種だけ）: 10取引日止める形で最大下落率 34%→27%、年率 8.9%→8.5%、1年の平均 −0.5pt、悪い5%の1年の損益 −18.5%→−16.5%。
   - 2015年〜（テーマの業種だけ、元の株）: 最大下落率 44%→26%、1年の平均 +0.8pt、悪い5%の1年 −11.1%→−8.9%。
   - 毎朝のツールと同じ形（2倍ETF込み・1年の区切り×乱数3）: 1年の平均は **87銘柄 −4.2pt・全業種 −2.7pt**、悪い5%の下落率は 41.9%→38.4%・39.9%→32.8%（20取引日止める形は −6.5pt・−5.0pt、36.2%・32.0%）。2倍ETFで戻りを取る分を止めている間に逃すので、元の株だけの計算より損益の差が大きい。
   - 実際の運用の期間: −36.5% → **−28.0%**（10取引日。10/15・10/16・10/30 に止まる）、−24.0%（20取引日）。
   - 決まった「下落率の目安」（損益の差 −1pt 以内）には届かない。止めるのは「ツール自身の売買が続けて負けたとき」だけで、相場の合図より取り逃しが少ない。
7. **実際の口座の損の多くは、ルールの外の売買から来ている**: ルールどおりの再現 −36.5% に対して、実際の口座は約 −67%（11/19）。差の多くは SNDK（ルール外、1枠の約2.5倍、2倍ETFを使う条件の外の SNDU）と、損切り価格を割った後も持った AMD・SNDK（11/06・11/09 の毎朝のレポートは「売り」）。

## 2. 最善策の提案（Claudeの見解。採用するかはユーザーが決める）

1. **ルールの土台（4つのルール・損切り15%・4銘柄）は変えない。** 長い下げを含む期間でも、ルールの売買はテーマの指数よりはるかに小さい損で済み、静観・乗り換えの決まりはどの期間でも1年の平均を下げた。「今までにない下げ」でも、今のところ損を区切る仕組み（損切り）が一番効いている。
2. **保険として「損で終わった売買が3回続いたら、新しい買いを10取引日止める」を加える。** ユーザーの感覚の「静観」を、相場の予想ではなくツール自身の成績で始め、決まった日数で自動で戻す形。長い下げの期間・2015年〜・今回のどれでも下げを小さくした。代わりに、ふだんの年は1年あたり約3〜4ポイント（2倍ETF込み）低くなる。もっと守りたいときは20取引日（今回 −24.0%、ふだんは約5〜6.5ポイント低い）。
3. **上がっている銘柄・業種への乗り換えは、今はしない。** 長い下げの期間でも短期国債より良くならず、今回は上がっている銘柄も業種もそろって下げている。
4. **一番効くのは、今のルールどおりに執行すること。** 買った日に証券会社に損切りの逆指値を置く、1枠の金額（資金÷4）を守る、ルール外の買いをしない、2倍ETFは案1（S&P500が上昇の局面）のときだけ。今回、実際の口座とルールどおりの再現の差は約30ポイントあった。
5. **前向きの記録で確かめ続ける。** 2026-11-23 から、週次レビューの節7に「今のルール／3回で10取引日止める／3回で20取引日止める／静観（短期国債）／上がっている業種／上がっている銘柄／S&P500」の仮の資金を並べる。今回が過去と違う下げなら、この記録に表れる。8週か、①の合図（SOXとS&P500が両方200日線の下）が消えた時点で見直す。

## 4. 注意

- B・Cの1999〜2012年は、生き残った銘柄だけ（2000年1月の構成銘柄の約半分）で、実際より良く出る。それでも止める形・乗り換えの良し悪しの比べ方（同じ銘柄の中での比較）には使える。
- B・Cの自作の計算（`--stage era`）は元の株だけ・急落の底は翌日の寄り付き。毎朝のツールと同じ形（2倍ETF・2%下の指値・テーマの外）は C の `opt2` の結果。
- 業種は今のYahooの分類を過去にも使っている。特殊な下げの印の条件は過去の下げを見て決めたもので後知恵を含む（Aで③が良く見えるのは主に2008年と今回の分）。
- この結果はルールの条件どおりに機械的に計算したもので、Claudeによる個別銘柄の売買判断ではない。
