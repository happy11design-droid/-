# 主導株（RSの上位10銘柄）の崩れで止める・売る

2026-11-08、ユーザーの指示「はいテストして」。`7月と今の下げの違い.md` で、ツールにとっての7月と今の違いは「持っている強い銘柄が上がり続けたか、崩れたか」で、SOX・社債・VIXでは前もって分からないと分かった。そこで、SOXではなく**ツールが買う強い銘柄そのもの**が崩れているかを測り、止める・半分にする・売る形を確かめた。

## 1. 結論

- **7月の警報の日（7/7）の時点では、主導株も崩れて見えていた。** 上位10銘柄の20取引日の高値からの下げの中央値は −23% で、2015年〜の13回で一番深かった（今の10/16は −20%）。50日線より下の割合は7月 50〜60%、今 90%。
- **過去は、警報の日に主導株が崩れていた回ほど、その後にツールが稼いでいた。** 87銘柄で上位10銘柄の8割以上が50日線より下だった回（2016-01・2018-10・2020-02・2022-01・2024-07）は、60取引日後の資金がすべてプラス（+5〜+27%）。ツールは急落の底などで戻りを買うので、主導株の崩れは「底に近い」ことが多かった。
- **主導株の崩れで止める・半分にする・売る6つの形は、どれも今のルールより悪かった**（1年の区切りで 87銘柄 −4.9〜−12.4pt、全業種 −1.1〜−4.8pt。年率・下落率の目安を満たす形はない）。
- **今回の下げだけを見ると、売る形はよく効く**（9/15〜10/30 に始めた場合の損益の中央値: 87銘柄 −21.9%→−11.0〜−11.9%、全業種 −21.8%→−8.1〜−8.4%。今のルールより良いのは 89〜99%）。ただし7月にも同じように売ってしまい、8〜9月の上げを逃す（2026年の成績 87銘柄 217%→176〜177%）。過去の下げでも、売った後に戻った回の方が多い。
- **採用できる形はない。** 7月と今を分けられる値は、崩れた後（損が出た後）にしか分からず、その時点では7月と今は同じに見えていた。

## 2. 測り方と形

- 主導株＝その日のRSの上位10銘柄（87銘柄ならテーマ監視銘柄、全業種ならAI関連の業種のS&P500構成銘柄）。引けで判定。
- L50＝主導株のうち50日線より下の割合。LDD＝主導株の20取引日の高値からの下げの中央値。
- SOXの下げの間＝SOXが60取引日の最高値から−15%以下になった日から、SOXが上向きの50日線を上回るまで（`7月と今の下げの違い.md` の「すべての下げ」）。

| 形 | 中身 |
|---|---|
| ⑬ | L50が50%以上の日はテーマを買わない（いつでも） |
| ⑭ | SOXの下げの間で、L50が50%以上の日はテーマを買わない |
| ⑮ | ⑭の日は保有2銘柄まで |
| ⑯ | ⑭になった日の翌取引日の寄り付きで持っているテーマ株を売り、⑭の日は買わない |
| ⑰ | SOXの下げの間で、LDDが−10%以下の日はテーマを買わない |
| ⑱ | ⑰になった日の翌取引日の寄り付きでテーマ株を売り、⑰の日は買わない |

「テーマを買わない・売る」は、87銘柄ではテーマの外の銘柄は買う・売らない。全業種ではAI関連の業種を買わない・売る。
