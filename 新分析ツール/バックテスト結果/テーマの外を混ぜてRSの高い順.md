# テーマの外を、監視銘柄と混ぜて全体でRSの高い順に買う形（2026-11-02）

2026-11-02、ユーザーの質問「テーマの外でもRSが高い順に並べた方が年率は良くなりますか？」から確かめた。

- **今の毎朝のツール**（`theme_scan.py:811`、バックテストの `outside=True`）は、テーマの外の候補を、同じ日の監視銘柄の候補の**後ろ**に付ける。テーマの外の中では、Aを先に、RSの高い順（もともとRS≧90の銘柄だけ）。
- **混ぜる形（今回）**: 後ろに付けず、監視銘柄とテーマの外を一緒にして、全体でRSの高い順に買う。AI半導体を先にするのは今のルールと同じ。空き枠にしか入らない、テーマの外の条件（RS≧90・30週線が上向き・業種の強さ上位20%）は同じ。
- 土台・数え方・判定は `買う順番_上昇率の測り方.md`（2026-11-01）と同じ。乱数30通り×2組、2015〜2021年と2022年〜の両方で上回ったか。判定の相手は「今のツール（テーマの外は後ろ）」。株価は2026-10-30まで。後知恵なしの監視銘柄と、87銘柄に固定（`--watch87`）の両方。

## 読み取り

- **混ぜても年率は上がらない**（後知恵なし 31.4〜31.5% → 30.2〜31.5%、87銘柄 35.4〜37.2% → 34.1〜35.2%）。2022年〜は上がる（後知恵なし 59% → 65%）が、2015〜2021年が下がる（後知恵なし 13〜14% → 10.7%、87銘柄 20.5% → 17%）。87銘柄の2022年〜は組によって上下で、差はない。
- 最大下落率は、後知恵なしで悪化（38.0% → 40.4%）、87銘柄でわずかに小さい（47.6〜48.1% → 46.2〜46.3%）。どちらも、年率を上げる根拠にならない。
- **テーマの外を足すこと自体が年率を下げる**（RSの高い順 → テーマの外を後ろに足す: 後知恵なし 34.6〜36.0% → 31.4〜31.5%、87銘柄 42.4〜44.0% → 35.4〜37.2%）。前に出すほど（混ぜる、警告の日は先に）下がる方向で、10/18・10/31 の記録（`テーマの外` の点検 9-7、`早めの警告とS2の日はテーマの外を先に買う.md`）と同じ傾向。
- → 買う順番は「監視銘柄 → テーマの外、その中はRSの高い順」のまま。テーマの外を続けるかは、10/18 に「著者が判定しているので続ける」とユーザーが決めたとおり。

## 注意

- 今回の「RSの高い順」「テーマの外を後ろに足す」の年率は、10/31 の記録（`実際の運用の期間の確認_2026-10-23/…警告の日はテーマの外を先に_87銘柄.md`: 87銘柄 45.0〜45.1%、32.6〜32.8%）より、1〜3ポイントずれている（株価の終わりは同じ10/30）。原因は特定できていない。
- 有力な原因: このセッションのキャッシュは空から作り直した。業種の一覧 `universe.json` を、リポジトリの `業種一覧.json`（ティッカー→業種）から作ったため、**S&P500の構成銘柄のうち26個（AIV・APC・AVB・BBBY・CAM・CSRA・EA・EMC・EQR・FOSL・INFO・LEG・NAVI・NFX・OI・PARA・PCL・POM・PSKY・QRVO・SATS・SBNY・SPLS・STI・WBD・XRX）の業種が空**になっている。元のキャッシュにあった `industry_extra.json` はリポジトリにない。Yahooが過去の株価を調整し直した可能性もある。
- 同じ実行の中で形を比べているので、形どうしの大小関係は信頼できる。絶対値は、記録の数字と並べて読まない。
- 「2026年9月〜」の列（実際の運用の期間）は、今回は計算していない。

- この結果はルールの条件どおりに機械的に計算したもので、Claudeによる個別銘柄の売買判断ではない。
