# 新分析ツール ルール選定の経緯（2026-09-25〜10-04）

今の状態の正は `新分析ツール/現状まとめ.md`、試したことの一覧は `新分析ツール/バックテストによる改善のまとめ.md`。このファイルは「なぜ今のルールになったか」を時系列でまとめたもの。

## 1. ツールを作った最初（9/25〜9/27）

- 目的: 既存ツール（Claude_ノートブック）とは別に、米国株スイングの新しいツールを作る。基本に忠実・テクニカル中心・判定をぶれさせない。
- 著者は本を読み込ませたNotebookLM（ボリンジャー・ミネルヴィニ・ワインスタイン・コナーズ）。
- 著者ごとに本のルールを数値にし、**今の87銘柄（後知恵あり）の直近3年**でバックテストして、ボリンジャーIII・ミネルヴィニ・ワインスタイン10週の3つを採用。
- **方式B（ユーザー決定）**: 買いはルール（スクリプト）が決め、著者は注文を止める理由があるときだけ【様子見】にする。
- 9/27: 新高値V2（ミネルヴィニのテンプレート＋ドンチャン＋オニールの考え方）と、急落の底（コナーズの考え方）を追加して5つのルールに。

## 2. 後知恵を除いた測り方へ（9/28〜9/29）

- 今の87銘柄は「今勝っている銘柄」を選んだ後知恵を含むため、毎週その時点の数値だけで監視銘柄を選び直すバックテスト（後知恵なしの監視銘柄、2015年〜）を作った。
- **このとき組み合わせに入れたのは4つ（押し目・ミネルヴィニ・新高値V2・急落の底）だけで、ワインスタイン10週は入れなかった**（Claudeの見落とし。毎朝のツールでは5つ使っていることを伝えていなかった）。
- 新高値V2に「直前2年の最高値以上」を追加（9/28）、同じ業種は2銘柄まで（9/28）。
- 資金ルール: 1トレードのリスク2%・7銘柄 → **4銘柄・1銘柄25%**（9/29 ユーザー決定。年率 約15.6%→約21.6%）。急落の底のRSI(2)≦10（9/29）。
- ユーザーの分割・買い下がり・損切りなしの売り方、ペトラリア氏の手じまいは、年率が下がるため採用しない（9/29）。

## 3. 試しても効かなかったもの（9/29〜10/1）

- 市場全体の判定（横ばい・MACD・ボリンジャー・VIX）で買わない・売る、早めに売るルール、チャートの形・酒田五法・指標で売る、売って買い直す、買いの条件を重ねる、テーマだけに絞る、上昇中の押し目、買う時刻、損切りの幅（8〜30%・なし）など。
- 結論: 買いのルールはかなり条件が整っていて、足すと下がる。

## 4. 売りと注文の改善（10/1〜10/2）

| 日付 | 採用した改善 | 理由 |
|---|---|---|
| 10/1 | 空き枠をS&P500の強い銘柄（テーマの外）で埋める | 両方の期間でわずかに良い |
| 10/1 | 押し目を上部バンドの指値で売る | 設計・確認の両方で良い |
| 10/1 | 順張りを反転の合図で半分売る | 乱数2組とも両方の期間で良い |
| 10/1 | 順張りをかぶせ線で全部売る（枠を空ける） | 年率 21.4%→26.4%。以前は乱数10通りで誤差に埋もれていた |
| 10/2 | 押し目・急落の底を出来高2倍の大陰線で全部売る | 年率 約+2ポイント |

- 10/1以降の採用の基準: 乱数20通りでふるい → 別の乱数50通り×2組で確認。3組とも設計期間（2015〜2021年）・確認期間（2022年〜）の両方で上回った形だけ。
- 10/2: 売り・買いの合図を今の測り方で全部やり直し（売り55種類、買いの条件39種類、新しい買いのルール10種類）。上回ったのは大陰線だけ。

## 5. 第三者検証と頑健さ（10/3）

- Gemini ディープリサーチに検証を依頼（`検証用_新分析ツールのルールと検証の全体像.md`）。指摘: 生存者バイアス・多重検定・確認期間のAIブーム依存。実際の期待は年率10〜15%、最大下落率50%を前提に。
- 確かめた: コスト（片道1%で利益が消える）、モンテカルロ（最大下落率50%超の確率6%）、年ごと（マイナスは2022年だけ）、ウォークフォワード（改善はその時点でも選ばれる。かぶせ線は確か、大陰線はまちまち）、生存者バイアス（FRC・CTLを加えても合図0件）、決算（またいだ方が良い。決算前に売ると悪化）。
- 最大下落率は含み損込み（約33%）で、確定した損益だけでは約29%。ユーザー: 「含み損の50%は気にならないが、確定して資産が50%になるのは嫌」。

## 6. 2倍ETF（10/3〜10/4）

- ユーザーの考え: 確定した損でなければ、レバレッジも検討したい。指数ETFは下落相場のときだけの決まりだが、**個別株の2倍ETFは例外**（10/1）。
- 信用取引1.5倍（6銘柄）は保留。2倍ETFを、ユーザーの証券会社（ムームー証券）で買える38銘柄で検証。
- 実際の値では、2倍ETFは元の株の2倍より年8〜28%目減りする（以前は年1%と仮定していた）。同じ元の株に複数あるときは、売買代金が多く目減りが小さいものを選ぶ（例: MU→MUU）。
- **採用（10/4）**: 目減りが年15%未満の2倍ETFは、全部のルールで株の代わりに使う。年率 株だけ約27%→約33〜35%、確定した損益だけの最大下落率 約30%→約31%（含み損込みは約45%）。対応表は毎週測り直し、条件を満たした銘柄は自動で復活。

## 7. ワインスタイン10週の整理（10/4）

- MU・SNDK・STXの下げをきっかけに、ワインスタイン10週がバックテストに入っていないことが分かった。
- 後知恵なしで初めて確かめると、加えると年率が下がる（27.1%→22.9〜26.3%）。勝率38%、2015〜2021年は1回平均マイナス。
- **ユーザー決定（10/4）**: ワインスタイン10週は参考の表示だけにし、著者には送らない。テーマ全体の局面の判定は、ワインスタインに送り続ける。
- これで、毎朝のツールの売買のルールと、バックテストのルールが一致した（押し目・急落の底・ミネルヴィニ・新高値V2の4つ）。
