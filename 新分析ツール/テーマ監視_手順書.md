# テーマ監視・スイング分析 手順書（下書き）

半導体・AIなど「今旬のテーマ」の銘柄だけを毎日監視し、条件がそろった銘柄だけを著者のノートブックに判定させる。
今の分析ツール（`チャート分析.txt`、ユーザーが選んだ個別銘柄の分析）とは別に動かす。

## 0. 守ること

- **買いの条件は、ユーザーが採用した売買ルール（下の手順T3の表。バックテストで検証済み）が決める。著者のノートブックは「注文を止める理由」だけを判定する**（ユーザー決定 2026-09-27、方式B）。止める理由は、本が禁じる形・状況、決算など避けるべき時期、悪材料の3つ。本が必須と明記していない「確認を待つ」などの追加条件では止めない（確認を待つとバックテストの成績が大きく下がったため）。
- **Claudeは売買の判断をしない。** 役割は、数値の計算・事実の収集・候補の抽出・送信・回答の全文表示に限る。テーマの移り変わりも、Claudeは数値を渡すだけで、判定はワインスタインのノートブックが行う。
- 著者に渡すのは数値と事実だけ。Claudeの解釈（相場天気予報の相場観を含む）は混ぜない。
- 急騰・急落そのものは売買の合図にしない（原因の調査のきっかけにする）。
- **S&P500・NASDAQ100などのETFは、スイングの売買にも資金の置き場所にも使わない**（ユーザー決定 2026-09-27。下落相場のときだけは可、それ以外の相場では持たない）。**個別株の2倍ETFなどのレバレッジ製品は、この決まりの例外**（ユーザーの指示 2026-10-01）。使っていない資金をSPYで持つ案（`バックテスト結果/モメンタムとSPYの組み合わせ.md`）は採用しない。バックテストでS&P500（SPY）の成績と比べることもしない（ユーザーの指示 2026-09-27）。
- **個別株の2倍ETF（2026-10-04 ユーザー決定）**: 2倍ETFがある銘柄（ユーザーがムームー証券で買えることを確認した38銘柄のうち、直近1年の目減りが年15%未満のもの）は、株の代わりに2倍ETFを買う。買う金額は株と同じ（資金の25%）。合図・損切り（元の株の買値の15%下、ETFでは約30%下）・手じまいはすべて元の株の値段で判定し、指値・逆指値はETFの値段に直して置く。どのETFかは `新分析ツール/2倍ETFの対応表.json`（`tools/leveraged_etf_check.py` が、1日の売買代金500万ドル以上で目減りが一番小さいものを選ぶ）。**毎週土曜の週次レビューで測り直し、復活・使わない・ETFの変更を表示する。毎朝のスキャンは表が8日より古ければその場で測り直す（`theme_scan.etf_table`）ので、条件を満たした銘柄は自動で復活する**（2026-10-04 ユーザーの指示）。毎朝のレポートの候補の「注文の目安」に「2倍ETFで買う: MUU（目減り 年12%）」と出す（`theme_scan.etf2x_of`）。著者には渡さない（著者は元の株について判定する）。保有銘柄.md には、ETFで買っても**元の株のティッカーと、買った日の元の株の値段**を書く（損切り・手じまいの判定に使う。ETFのティッカー・株数は備考に）。根拠: `バックテスト結果/2倍ETFを使う決まり.md`（株だけ 年率約27%・確定した損益だけの最大下落率29.7%・含み損込み33% → 年率約33%・30.9%・45%。ルールごとに分けるより全部のルールに使う方が良く、目減り15%以上を除くと確定した損の最悪が39.9%→38.3%）
- 著者ノートブックへの質問は1日約175回が上限**と見積もっていたが、2026-09-27は約80回で空の応答（エラーではない）になった**。大量に送る検証（`tools/replay_moves.py` など）は、毎朝のRoutineの分を残して1日数十回までにする。候補・保有銘柄は、著者ごとに3銘柄程度をまとめて1回で送る。

## 2. 毎日の流れ（引け後＝日本時間の朝）

### 手順T1〜T3: データの取得・テーマの状態・候補の抽出（スクリプト1本、約20秒）
```bash
tools/theme_scan.py "$D/scan.md"
```
- 監視銘柄（`テーマ監視銘柄.md`、87銘柄）とS&P500の日足（2年分）を取得し、次を書き出す。数値と事実だけで、売買の判断はしない。
  1. グループごとの騰落率（1週・1カ月・3カ月）と順位、50日線より上の銘柄の割合。
  2. テーマ指数（監視銘柄の等金額平均）の30週線による局面（ワインスタインのステージの近似）と、早めの警告（監視銘柄のうち50日線より上の割合が40%未満、かつテーマ指数が50日線より下）。
