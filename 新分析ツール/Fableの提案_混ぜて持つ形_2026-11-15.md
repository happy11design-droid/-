# いくつかの形を混ぜて持つ方法（設計と、既にあるファイルでの試し計算）

## 0. 先に結論

1. **混ぜても年率は生まれない。** 混ぜた形の年率は、混ぜた口の年率のほぼ平均になる。平均より上に出る分（毎年割合を戻す効き目）は、口どうしの動きが大きく違うときだけ出る。
2. **ルールの形どうしを混ぜる案は、手間に見合わない見込み。** 成績で選んだ上位14形を等しく混ぜても、別の半分の期間では今のルールより少し下だった（全業種 −0.9pt、87銘柄 −0.4pt）。当たり外れの幅は半分以下になるが、「何も足さない」（今のルールのまま）には、その幅がそもそもない。
3. **混ぜる効き目が大きいのは、監視銘柄（87銘柄と全業種）を混ぜる形だけ。** 記録の中で、動きが一番違う組み合わせがこれだった。半分ずつ持つと、税込みの年率 36.3%（87銘柄だけ 39.7%、全業種だけ 29.5%）、最大下落率 37%（49%・35%）。空の枠から始めた1年の悪い5%は −9.5%（−15.2%・−11.9%）で、どちらの口だけより良い。
4. ただし案1は、今の毎朝の形（87銘柄）と比べると年率が −3.4pt 下がる。今の下落率の目安（年率の低下1pt以内）は満たさない。「年率 −3.4pt と引き換えに最大下落率 −12pt」を採るかどうかは、ユーザーの判断になる。
5. 保留の形は、割合で持てば効き目も害も割合どおりになる（案2）。新しい発見はない。

## 2. 既にある結果のファイルで数えたこと

### 2-1. 成績で選んだ形を混ぜると、選びすぎは消えるか（`allforms_screen_*.json`、417形）

M1と同じ分け方（重ならない1年の区切りを半分に分け、選ぶ側で上位を選び、残りの半分で確かめる）。上位1形の数字はM1と一致した（全業種 +14.1→−2.2pt、87銘柄 +28.4→+0.4pt）。

| 選ぶ側で選んだ形 | 全業種: 選ぶ側 → 確かめる側 | 87銘柄: 選ぶ側 → 確かめる側 |
|---|---|---|
| 上位1形 | +14.1 → −2.2pt | +28.4 → +0.4pt |
| 上位5形を等しく | +11.7 → −1.6pt | +21.1 → −0.2pt |
| 上位14形を等しく（今の目安に近い選び方: 両方の監視銘柄でプラス・良い割合55%以上） | → −0.9pt（確かめる側のばらつき 3.4pt。上位1形は 7.3pt） | → −0.4pt（4.8pt。上位1形は 13.4pt） |
| 417形を全部等しく | −2.1 → −2.1pt | −3.1 → −3.1pt |

- 混ぜると、確かめる側のばらつき（当たり外れの幅）は半分以下になる。形どうしの「今のルールとの差」はほとんど別々に動く（相関の中央値 0.13〜0.16）ので、平均すると打ち消し合う。
- しかし確かめる側の平均は、何形混ぜても今のルールを上回らない。形の平均が今のルールより悪く（−2〜−3pt）、良く見えた形もそこへ戻るため。

## 3. 案1: 監視銘柄を混ぜる（87銘柄の口と全業種の口）

1. **どの形を混ぜるか**: ルールの形は選ばない（どちらの口も今のルール）。混ぜるのは監視銘柄で、候補は記録に2つしかない（今の87銘柄と、毎週その時点の数値で選び直す全業種。AI・半導体を先に買うのは同じ）。成績を見て選ぶ余地がないので、選びすぎにならない。
2. **混ぜ方**:
   - 資金を半分ずつ2つの口に分ける。口ごとに4枠、1銘柄は口の資金の25%（全体の12.5%）。待っている現金は口ごとにQQQ。
   - 毎年1月の最初の取引日に、口の資金を半分ずつに戻す。保有は売らず、口の間で待っている現金（QQQ）を移すだけにする。足りない分は、次に売った代金で埋める。
   - 同じ銘柄を2つの口が持つときは、そのまま別々に持つ（合わせて全体の25%で、今の1銘柄の上限と同じ）。同じ業種2銘柄までの決まりは口ごと（同じ業種に最大4銘柄になるが、金額の上限は全体の50%で今と同じ）。
   - **依頼の1.の4との関係**: 口ごとに4枠のままなので、「同じ一覧の中でRSの低い候補まで買う」形（銘柄数5〜7が悪かった理由）にはならない。実際の保有は最大8銘柄・1銘柄12.5%になるが、2つの口は同じAI銘柄を持つことが多く、重なった分は25%になる。3銘柄の形のように揺れが増えることもない（乱数による揺れ 22.0pt・15.9pt → 14.0pt）。弱点は実務の方で、資金12,000ドルでは1銘柄1,500ドルになり、株価の高い銘柄は株数の端数が大きく、最低手数料も効く。
3. **なぜ1つを選ぶより良くなりうるか**:
   - 87銘柄は今の勝ち組を選んだ一覧で、過去の数字は良く出ている。全業種は後知恵がないが、過去の数字は低い。これからどちらが良いかは分からない。2026-10-25 に「87銘柄のまま」と決めたこと自体が、1つを選ぶ賭けになっている。
   - 効く問題: 1（選びすぎ。監視銘柄の選び方）、2（時期で入れ替わる）。効かない問題: 3（状況で選ぶ形）、5（見送る・待つ形）。6（混ぜた例）に、新分析ツールの中の2つ目の例を足すことになる。
   - 重なり: 毎日の損益の相関は0.82。測り方は2つ。(a) 2つの口の毎日の損益の差の大きさ（年率）。(b) 売買の一覧（`OPT_TRADELIST`）から、同じ日に両方の口が持っている銘柄の金額の割合。(a) が年10%より小さい組み合わせは、混ぜても中間の値になるだけで、当たり外れの幅も毎年戻す効き目も出ない（2-3）。
4. **確かめ方**:
   - `backtest_retest.py` は変えない。2つの口は別々の資金なので、形ごとの毎日の資金（`OPT_EQDUMP`・`OPT_EQDUMP_ALL=1`・`OPT_TAX=1`）を後から混ぜる計算で正確に出る。新しいスクリプト `tools/mix_check.py` を作る（土台は `tools/fable_mix_quick/mixD.py`〜`mixG.py`）。
   - 1年の区切りは、(a) 空の枠から始めた形は `st2roll_87.json` と `st2roll_free.json` の同じ始める日・同じ番号の乱数の1年の損益を平均する（口は1年のあいだ戻さない前提で正確）。(b) 1年の中の下落率は、毎日の資金から250取引日の区切りを10取引日ごとに取って出す。
   - 物差し: 87銘柄だけ・全業種だけの**両方**と比べる。年率・最大下落率・2015〜21年と2022年〜・年ごと（12年のうち、悪い方の口を上回った年の数）・1年の区切り（損益の差、良い割合、損益の悪い5%、悪い5%の下落率）。今の年率の目安（両方の監視銘柄で今のルールを上回る）は、監視銘柄そのものを混ぜる形には当てはまらないので、「悪い方の口を上回り、良い方の口の最大下落率を下回るか」を見る。
   - M1（`tools/pbo_check.py` の毎日の資金の形）: 16個のブロックの分け方ごとに、(i) 半分ずつの形の年率が、その半分の期間で悪かった方の口を上回る割合、(ii) 最大下落率が、良かった方の口より小さい割合、を数える。形は先に決めた1つなので、組の形の数は K=1。
   - 税: 口の間は通算しない前提（少し厳しめ）。割合を戻すときは保有を売らないので、戻すことによる税は出ない。
5. **先に書く見込み**（2-4の数字。同じ計算を別のセッションが再現するはず）:
   - 年率 36.3%（87銘柄だけより −3.4pt、全業種だけより +6.8pt）、最大下落率 37%（−12pt、+2pt）、空の枠から始めた1年の悪い5% −9.5%（+5.7pt、+2.4pt）。
   - **効かないと分かる条件**: 手数料と最低手数料を入れた形（1銘柄が半分の金額になる）で年率が35%を下回る。または、分け方を変えた確かめ（M1）で、最大下落率が87銘柄だけより小さい割合が70%に届かない。
   - 2026-10-05 に始めた今回の期間は、87銘柄 −23.6%・全業種 −34.6%（11/05まで）で、半分ずつなら約 −29%。今回の下げには効いていない。
6. **実装の手間**: 確かめは後から混ぜる計算だけで、新しいバックテストは要らない（1〜2時間、メモリは小さい）。毎朝の仕組みは大きく変わる。全業種の監視銘柄を毎週選び直す処理（今は `tools/backtest_rotation_v2.py` の中だけ）を `theme_scan.py` に入れ、候補の表・保有銘柄の表・株数の目安を口ごとに出す必要がある。今の「テーマの外」（空き枠だけ、監視外の強い銘柄で埋める）を、資金の半分の口に広げる形に近い。**変えるかはユーザーが決める**（案として書くだけ）。
7. **記録の確認**: `新分析ツール/バックテスト結果/` と `新分析ツール/*.md` を「監視銘柄を混ぜ」「87銘柄と全業種を」「半分ずつ」「口に分け」「混ぜ」「アンサンブル」で検索した。監視銘柄を口に分けて同時に持つ検証は0本（「混ぜ」が当たるのは、ニュースを混ぜた検証と、ペトラリア氏の手じまいの記録だけ）。近いのは「テーマの外で空き枠を埋める」（`テーマを変えるか.md`: 87銘柄 42%→36%）で、これは空き枠だけを使う形。

## 4. 案2: 保留の形を割合で持つ

1. **どの形を混ぜるか**: 保留の3つのうち、合図が今のルールと同じで、乗り物（2倍ETFか元の株か）だけが違う2つ（QQQ＋ステージ2の後40日は2倍ETF、2倍ETFをいつでも使う）。信用取引1.5倍は入れない。25%混ぜるだけで87銘柄の最大下落率が53%になり、許容の50%を超えるため。
2. **混ぜ方**: 口は分けない。1つの口で、その形なら2倍ETFで買う場面のとき、枠の金額の半分を2倍ETF、半分を元の株で買う。枠の数・1銘柄の金額・同じ業種の決まりは今のまま。**依頼の1.の4との関係**: 保有の数も1銘柄の金額も変わらない。
3. **なぜ良くなりうるか**: 採る・採らないの二択をやめ、半分だけ賭ける。当たれば半分の上乗せ、外れれば半分の害で済む。効く問題は1だけ。合図が全部重なる（今のルールとの毎日の差が年3.8〜8%）ので、当たり外れの幅を小さくする効き目も、毎年戻す効き目もない。
4. **確かめ方**: 後から混ぜる計算で足りる（合図が同じなので、口に分けた計算と1つの口で半分ずつ買う形は同じになる）。`hold_eq_*.json` を使い、2-3の表を `tools/mix_check.py` で再現する。物差しは今の目安（5節の7・8）とM1。
5. **先に書く見込み**: 今50%＋ステージ2 50% で、全業種 年率 +0.9pt・最大下落率 +3pt、87銘柄 +0.6pt・変わらず。ステージ2の分の上乗せはもともと小さく（年 +0.7〜1.3pt、偶然でも6回に1回は出る大きさ。`M1_保留中の形に当てる.md`）、その半分になる。**効かないと分かる条件**: 再現した数字が、混ぜた2つのちょうど中間から0.3pt以上ずれない（＝混ぜること自体の上乗せがない）。その場合、これは「混ぜる策」ではなく「保留の形を半分だけ採るかどうか」の判断になる。
6. **実装の手間**: 確かめ30分。毎朝の仕組みは、株数の目安を「半分は2倍ETF、半分は元の株」と出すだけ。保留の扱いは変えない（採るかはユーザーが決める）。
7. **記録の確認**: 「半分は2倍ETF」「割合で持つ」で検索して0本。近いのは `2倍ETFに置き換えた場合.md` の「2倍ETFを半分の額で持つ」（枠の金額を半分にする形で、株より悪い 17.3%）。今回は枠の金額は変えず、乗り物を半分ずつにする。

## 5. 案3: 中身の違うルールの形を等しく混ぜる

1. **どの形を混ぜるか**: `点検_2026-11-12_全部の形のやり直し.md` 2節の本番まで残った14形から、成績ではなく「変える場所」が違うものを1つずつ、5形。乗り物（QQQ＋ステージ2の後40日は2倍ETF）、損切り（18%）、順張りの買い（一目の転換線が基準線より上）、保有の数（大手4社の決算㉒の後は2銘柄まで）、逆張りの買い（急落の底をRSI(2)≦15）。銘柄数3は入れない（混ぜても1年の悪い5%が良くならず、税引き後の通しで下がる形のため）。
2. **混ぜ方**: 資金を5つの口に等しく分け、口ごとに4枠。**依頼の1.の4との関係**: ほとんどの売買は5つの口が同じ銘柄を同じ日に買うので、保有は今とほぼ同じ4銘柄・25%になる。違いが出るのは、一部の口だけが買う売買（1銘柄が全体の5〜20%）と、一部の口だけが売る場面。1つの口にまとめるなら「その売買を取る形の割合×25%」を買う形になるが、資金12,000ドルでは5%が600ドルで、実際には動かしにくい。
3. **なぜ良くなりうるか**: 形どうしの「今のルールとの差」は別々に動く（相関 0.13〜0.16）ので、混ぜると当たり外れの幅が半分以下になる。効く問題は1だけ。ただし平均は上がらない（2-1）。
4. **確かめ方**: 5形の毎日の資金（`OPT_EQDUMP_ALL=1`・`OPT_TAX=1`）を出し、後から混ぜる。5形のうち `hold_eq_*.json`・`tax_*.json` にあるのはステージ2だけなので、残り4形は新しく出す必要がある（1形あたり両方の監視銘柄で約1時間、同時に2本まで）。1年の区切りは `st2roll_*.json` の平均で、新しい計算なしに出る。M1は、選ぶ側で「5形を等しく」と「今のルール」を比べる形（K=1）と、2-1の表（成績で選んだ場合）の両方を書く。
5. **先に書く見込み**: `st2roll` の1年の区切りでは、今のルールとの差 +1.9pt（全業種、良い割合70%）・+1.8pt（87銘柄、66%）、1年の悪い5%は −13.0→−8.8%・−15.9→−13.0%。ただしこの14形は同じデータで選んだ後の形なので、2-1の割り引き（−0.9pt・−0.4pt）が本当の見込みに近い。**効かないと分かる条件**: 税込みの通しで、両方の監視銘柄の年率が今のルールを上回らない。上回っても、その差がステージ2の口の分（2-3の5分の1）で説明できる。
6. **実装の手間**: 確かめは半日（新しい毎日の資金4形×2）。毎朝の仕組みは5つの形の合図を並べて出す必要があり、大きい。**採らない見込みなので、1年の区切りの確かめ（新しい計算なし）だけ先に行い、そこで見込みどおりなら毎日の資金は出さない**ことをすすめる。
7. **記録の確認**: `バックテストによる改善のまとめ.md` と `バックテスト結果/` を「混ぜ」「アンサンブル」「複数の形を」「形を分けて」で検索して、形どうしを同時に動かす検証は0本（依頼の確認と同じ）。

## 6. 外した案と理由

| 案 | 外す理由 |
|---|---|
| 同じルールで、候補の取り方（乱数）だけ違う口に分ける | 実際の運用には乱数の揺れがほとんどない（2.3〜2.8pt）。口ごとに違う候補を取らせると、RSの高い候補を見送ることになり、1年の損益が約7pt下がる（2-2） |
| 過去の成績で口の重みを変える | 選ぶ側で良かった形は、確かめる側で今のルールを下回る（2-1）。依頼の1.の3（状況で選ぶ形は負ける）と同じ失敗になる。重みは先に決めて固定する |
| 銘柄数3の口を混ぜる | 今のルールと半分ずつにしても、1年の悪い5%が良くならない（−13.0→−13.5%、−15.9→−16.0%）。税引き後の通しで下がる形でもある |
| 信用取引1.5倍の口を混ぜる | 25%混ぜるだけで87銘柄の最大下落率が 49%→53%、悪い5%の下落率が 53.3% になり、許容の50%を超える |
| 順張りの口と逆張りの口に分ける | 片方の合図がない時期に、その口の資金が余る。新高値V2を外すと1年の損益が −14〜−26pt、順張り・逆張りのどちらを先に買っても差が出なかった記録（`直した数え方で年率を上げる形を探す_1.md`）から、枠を固定して分ける利が見えない |
| 例B（合意で大きさを決める）を合図の違う形に当てる | 1つのバックテストの中で口を分ける実装が要るうえ、中身は案3と同じで、見込みが −0.9〜−0.4pt |
