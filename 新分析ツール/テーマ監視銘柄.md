# テーマ監視銘柄

新分析ツールが毎日監視する銘柄。**ユーザーが編集する一覧**で、Claudeは依頼なく銘柄を足し引きしない（候補の提案までは可）。

- 対象: S&P500・NASDAQ100の構成銘柄のうち、半導体・AI・光通信のテーマに入る銘柄。ETFは含めない（ETFは長期戦略用）。
- 件数の目安: 30〜50銘柄。ちょる子さんの手法の「テーマに沿った業界トップ企業を30〜50銘柄リストアップし、定点観測する」に合わせる（Claude_ちょる子【出典: 投資家ちょる子_詳細マニュアル】）。
- 業種はYahoo Financeの分類。時価総額は2026-09-25時点のおおよその値（十億ドル）。
- ユーザー自身が選んだ個別銘柄の分析は、これまでどおり `チャート分析.txt` で別に行う（この一覧とは別）。
