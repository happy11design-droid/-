# 恩株ツール 手順書

目的: これから短い期間（数カ月〜1年）で2倍になりやすい株を合図で見つけ、2倍になったら元本分を売って「恩株」を増やす（`恩株ツール/現状まとめ.md`）。
新分析ツール（スイング）とは別の資金・別のルール。

## 1. 採用ルール（`恩株ツール/採用ルール.json`）

2026-10-10 の探索（`バックテスト結果/買い方・売り方・現金の探索.md`）で一番良かった組み合わせ。ユーザーの指示で変える。

| 項目 | ルール |
|---|---|
| 対象 | S&P500の今の構成銘柄 |
| 合図 | 終値で、6カ月（126取引日）で+100%以上 かつ 52週高値を更新 かつ 直近の四半期の売上の前年同期比≧10% |
| 買い方 | 合図の翌日の寄り付き。**3銘柄まで**（恩株は数えない）。1銘柄に（待っている現金＋保有株の買値の合計）÷3 |
| 枠より合図が多いとき | 6カ月の上昇が大きい順に選ぶ（ランダムとの差はわずか） |
| 2倍 | 終値が買値の2倍になったら、55.7%（税引き後で元本が戻る株数）を売る。残りは恩株として持ち続ける |
| 損切り | 終値が買値の−30% |
| 期限 | 189取引日（約9カ月）で2倍にならなければ売る |
| 乗り換え | しない（成績が下がった） |
| 待っている現金 | QQQに置く。買うときにQQQを売って資金にする |

## 2. 毎朝の合図の通知

```
D=/tmp/onkabu/$(TZ=Asia/Tokyo date +%F); mkdir -p "$D"
tools/onkabu_scan.py "$D/scan.md"      # 1分ほど。S&P500の日足と、候補の売上（SEC）を取る
```

`scan.md` の内容:
1. **今日の合図**: 合図が出た銘柄（6カ月の上昇が大きい順）、株数の目安、2倍・損切りの価格の目安
2. **保有銘柄**: `恩株ツール/保有銘柄.md` の銘柄の、2倍・損切り・期限の到達
3. **合図に近い銘柄**（参考）

Claudeは `scan.md` をそのまま表示する。合図・売りの条件はルール（スクリプト）が決め、Claudeが独自に銘柄を選んだり、売買を判断したりしない。

## 3. 約定の記録

ユーザーが「〇〇を△△ドルで□株買った」「〇〇を2倍で売った」と伝えたら、`恩株ツール/保有銘柄.md` を書き換える（保有→恩株、行の削除）。
