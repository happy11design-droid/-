# 恩株ツール 手順書

目的: これから短い期間（数カ月〜1年）で2倍になりやすい株を合図で見つけ、2倍になったら元本分を売って「恩株」を増やす（`恩株ツール/現状まとめ.md`）。
新分析ツール（スイング）とは別の資金・別のルール。

## 1. 採用ルール（`恩株ツール/採用ルール.json`）

2026-10-10 の探索（`バックテスト結果/買い方・売り方・現金の探索.md`）で一番良かった組み合わせ。ユーザーの指示で変える。

| 項目 | ルール |
|---|---|
| 対象 | S&P500の今の構成銘柄 |
| 合図 | 終値で、6カ月（126取引日）で+100%以上 かつ 52週高値を更新 かつ 直近の四半期の売上の前年同期比≧10% |
| 買い方 | 合図の翌日の寄り付き。**3銘柄まで**（恩株は数えない）。1銘柄に（待っている現金＋保有株の買値の合計）÷3 |
| 枠より合図が多いとき | 6カ月の上昇が大きい順に選ぶ（ランダムとの差はわずか） |
| 2倍 | 終値が買値の2倍になったら、55.7%（税引き後で元本が戻る株数）を売る。残りは恩株として持ち続ける |
| 損切り | 終値が買値の−30% |
| 期限 | 189取引日（約9カ月）で2倍にならなければ売る |
| 乗り換え | しない（成績が下がった） |
| 待っている現金 | QQQに置く。買うときにQQQを売って資金にする |

## 2. 毎朝の合図の通知（Routine、平日7:27 JST。2026-10-12〜）

```
D=/tmp/onkabu/$(TZ=Asia/Tokyo date +%F); mkdir -p "$D"
tools/onkabu_scan.py "$D/scan.md"      # 1分ほど。S&P500の日足と、候補の売上（SEC）を取る
```

`scan.md` の内容:
1. **今日の合図**: 合図が出た銘柄（6カ月の上昇が大きい順）、株数の目安（1銘柄4,500ドル）、2倍・損切りの価格の目安、**買う順番**（倍増用に取っておいた資金で買うのは1銘柄目。2銘柄目以降は恩株ツールの残りの現金で買える範囲で。資金は新分析ツール12,000ドル・恩株ツール4,500ドルで分ける（2026-10-12 ユーザー決定））
2. **保有銘柄**: `恩株ツール/保有銘柄.md` の銘柄の、2倍・損切り・期限の到達（到達したら太字で「55.7%を売って恩株に」「全部売る」）
3. **合図に近い銘柄**（参考）

Routine では:
- `scan.md` の全文をそのまま表示する。合図・売りの条件はルール（スクリプト）が決め、Claudeが独自に銘柄を選んだり、売買を判断したりしない。NotebookLMには送らない。
- `scan.md` を `恩株ツール/通知/YYYY-MM-DD.md` として、Routine用ブランチ `claude/onkabu-daily` にコミット・プッシュする（mainには入れない）。
- 合図か、保有銘柄の売りの条件（2倍・損切り・期限）が出た日は、レポートの冒頭にそのことを短く書く。

**買うときの流れ（moomoo証券）**: 合図はその前の日の終値で決まる。倍増用のQQQを売って、合図の翌日の寄り付きで買う。売却代金がすぐに使えない場合は、合図の翌日にQQQを売り、その次の日の寄り付きで買う（1日遅れでも成績はほぼ同じ。`バックテスト結果/倍増ツールを1日遅れで買う場合.md`）。
