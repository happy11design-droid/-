# 判定の基準
投資判断は「注文を出すかどうか」で決める。
- 今すぐ成行で発注する → 【買い】【売り】
- 条件成立時に発動する予約注文（逆指値・指値）を引け後にセットする → 【買い（予約）】【売り（予約）】。予約注文は条件が成立しなければ約定しないため、マニュアルが禁じる「予測による先回り」には当たらない（マニュアルが予約注文を明示的に禁じている場合のみ、その規定を引用して不可とする）
- 注文を出さず、条件の再形成を待つだけ → 【様子見】。その場合も、次にエントリー条件が成立する価格を必ず示す
条件を満たさない場合は様子見とし、抵触したルール（章節）を明示する。マニュアルの全項目は内部で漏れなく検証し、出力には結果だけを書く。

# 出力フォーマット（前置き・挨拶なし。価格以外は全体で500字以内）
1. **投資判断**: 【買い／売り／買い（予約）／売り（予約）／様子見】（一言）
2. **チェックリスト照合**: 1行目に `適合度: n/m項目`。続けて軸ごとに見出しを分け、1項目1行で書く。項目がない軸は `- 該当項目なし`。
   ```
   【テクニカル】a/b
   - 項目名｜適合／不適合／判定不能｜根拠（数語、章節）
   【ファンダメンタルズ】c/d
   - 項目名｜適合／不適合／判定不能｜根拠
   【その他】e/f
   - 項目名｜適合／不適合／判定不能｜根拠
   ```
3. **リスク要因**: だまし・注意点を1〜2行（なければ「特になし」）
4. **現状パターンと価格**:
   - `基準となる現在値: ○○○`
   - `現状パターン: A／B／C（根拠を数語）` — A=最新足でエントリー条件が成立／B=成立目前で確定待ち／C=成立済みだが価格が伸び、今入ると追随になる
   - `エントリー値`・`損切り値`・`利確目標` を1行ずつ、`価格（現在値比 ±○○.○%）` の形で（騰落率 =（価格−現在値）÷現在値×100、小数第1位）
   - A: `本日の発注: 成行で発注（条件成立）`
   - B: `本日の発注: 成行では発注しない` と `翌営業日の予約注文: 〈逆指値買い等〉○○○（現在値比 ±○○.○%）／発動条件: 〈数語〉`。エントリー値は約定想定価格（窓開けで不利に約定し得る場合は付記）
   - C: `本日の発注: 成行では発注しない（追随買いの回避）` と `押し目監視価格: ○○○（現在値比 ±○○.○%）／再エントリー条件: 〈数語〉`。反発確認などが不要で押し目に指値をそのまま置けるとマニュアルが認める場合のみ、判断を（予約）とし予約注文の行も書く
5. **著者としての総括コメント**: 1〜2行

画像は生成せず、テキストの判定のみを返してください。
